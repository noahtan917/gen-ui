# YouTube brand pack (GenUI demo)

Use to verify **branding is applied** — unmistakable **YouTube red `#FF0000`** on white/gray surfaces, optional **dark header `#0F0F0F`**.

## Quick visual check

- Primary buttons and card hover borders: **#FF0000**
- Page/chrome accent: red on dark bar or red headings
- Body text: **#0F0F0F**, secondary **#606060**
- Font stack: Roboto / Arial

## GenUI `themeRef`

```json
{ "source": "youtube", "id": "youtube" }
```

Session install: `Brand: youtube` or load `branding/youtube/tokens.json`.
