# 917v.ai corporate website — UI kit

Built from the 917V Brand Book 2.1, chapters 10 (layout), 12 (voice) and 14 (websites). No live site or code was supplied, so this follows the book's website spec rather than a shipped page.

- `index.html`: click-through. Header nav → AgentBase (product site), About, "Talk to us" → contact form with toast. "See the console" opens the dashboard kit.
- `Shared.jsx`: Frame (corner Facet), Section shell, type presets, corporate header/footer.
- `Home.jsx`: Frame hero on 917 Black, three pillars, Build up / cut down on Deep Blue, AI Labs product family, proof points, CTA band.
- `AgentBasePage.jsx`: product site pattern. The product lockup sits in the header, 917V appears only in the footer with "A 917V product", and the page has an outcome headline, a product screen, capabilities and code.
- `AboutPage.jsx`: About and Contact.

Copy is taken from the brand book (messaging house, boilerplate, approved lines). No photography was supplied; add real imagery per chapter 11.
